Machine interface

The same examination service is available programmatically over the web and from the command line. Responses are structured data.

Web endpoints

Standard engine, high-efficiency engine, concurrent bulk, and the register feed.

GET  /api/scan?url=https://example.com            # standard engine
GET  /api/scan_fast?url=https://example.com       # high-efficiency engine
POST /api/scan_bulk  {"urls": ["https://a", "https://b"]}   # bulk, max 20
GET  /api/history                                 # examination register (data file)

Command line

No server required — scan straight from a terminal.

python scanner.py https://example.com            # command line, standard
python fast_scanner.py https://a https://b        # command line, high-efficiency + bulk
